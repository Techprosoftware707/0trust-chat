# CRL distribution hosts the Rust SDK's certificate verifier may fetch over plain http.
#
# Certificate revocation lists are signed by their CA, and public CAs publish them over http.
# Since 2025 Let's Encrypt (and other CAs) put only a CRL, no OCSP responder, in their
# certificates; without access to these hosts the SDK could not check such a certificate
# (org.rustls.platformverifier.CertificateVerifier). Nothing else may use plain http.
#
# Source: rustls-platform-verifier 0.7.1 (the version in sdk-android 26.09.28), Android component
# 0.2.0, android/rustls-platform-verifier/src/main/res/xml/network_security_config.xml (generated
# by upstream from the CCADB; rustls/rustls-platform-verifier#221), all with includeSubdomains,
# plus c.lencr.org so Let's Encrypt's later intermediates (<name>.c.lencr.org) are covered too.
# Refresh it from upstream when the SDK's rustls-platform-verifier changes.
#
# Both res/xml/network_security_config.xml files (main and debug) must list exactly these hosts in
# their one plain-http <domain-config>; the Gradle task checkNoTlsBypass enforces it.
