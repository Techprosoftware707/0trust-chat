Install the whole {{ brand.short_name }} stack — a Matrix homeserver, web chat, calls, website, customer portal and private operator console — on your own Ubuntu 24.04 server.

Requirements

  • A fresh Ubuntu Server 24.04 LTS (x86_64 or arm64) with a public IP.
  • At least 2 vCPU, 4 GB RAM and 40 GB disk for a small community; see the admin guide for sizing.
  • A domain with DNS records for example.com, app.example.com, matrix.example.com, rtc.example.com (calls) and ops.example.com pointing at the server.
  • Ports 80/tcp and 443/tcp+udp reachable from the internet; for calls also 7881/tcp, 7882–7889/udp and 3478/udp; 51820/udp for WireGuard.

Install

git clone <your Lumen repository> lumen
cd lumen
sudo bash install.sh

The installer asks for your domains and operator email (or reads lumen.conf for unattended installs), checks the host and DNS, installs Docker from Docker's official repository, generates unique secrets, obtains certificates, configures the firewall, starts every service and verifies the public endpoints. At the end it shows a summary and how to obtain your one-time operator setup link.

Reach the operator console

The console is not on the public internet. It accepts connections only through a WireGuard tunnel, an SSH tunnel or addresses you allow-list.

  • WireGuard (on by default). The installer brings up the tunnel and creates a first operator device profile; show it as a QR code with sudo ./lumenctl wireguard show-profile. Add more devices on the console's WireGuard page or with sudo ./lumenctl wireguard add-peer laptop. Every device gets its own preshared key. If the host can't run WireGuard, the install continues with the SSH tunnel.
  • SSH tunnel. ssh -N -L 8443:127.0.0.1:8443 you@server, then open https://ops.example.com:8443/ with ops.example.com pointing at 127.0.0.1 in your hosts file. sudo ./lumenctl admin-tunnel prints the exact steps for your server.

WireGuard is only for administration. Chats don't use it: messages are protected by Matrix end-to-end encryption on their own. Operators can turn it off with sudo ./lumenctl wireguard disable.

Operate

CommandPurpose
sudo ./update.shBack up, update images and code, migrate, health-check, roll back on failure
sudo ./backup.shEncrypted backup of databases, media, keys and configuration
sudo ./restore.shVerify and restore a backup
sudo ./healthcheck.shQuick pass/fail of every component
sudo ./diagnose.shExplain DNS, TLS, federation, database, SMTP and webhook problems
sudo ./lumenctl wireguard statusShow the tunnel and its operator devices
sudo ./uninstall.shRemove the stack (asks before deleting any data)
