How operator access works

  • {% icon "globe-lock" %}

    Off the public internet

    This console only accepts connections through this tunnel, an SSH tunnel or allow-listed addresses.

  • {% icon "key-round" %}

    A preshared key per device

    Recorded tunnel traffic stays confidential even against a future quantum computer, as long as the key stays secret.

  • {% icon "messages-square" %}

    Separate from chats

    Messages never use this tunnel; they're end-to-end encrypted by Matrix.
