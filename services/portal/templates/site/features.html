Features

Everything a private conversation needs

{{ brand.short_name }} pairs the mature Matrix encryption stack with an interface designed for people who just want to talk safely.

{% icon "messages-square" %}

Messaging

  • {% icon "check" %} End-to-end encrypted direct messages and group rooms, on by default
  • {% icon "check" %} Replies, reactions, edits and deletions
  • {% icon "check" %} Typing indicators, read receipts and presence (where the server enables it)
  • {% icon "check" %} Delivery states taken from real server events: sending, sent, seen
  • {% icon "check" %} Encrypted file and image sharing with in-browser decryption
  • {% icon "check" %} Search across the messages your device can decrypt — locally, never on the server
  • {% icon "check" %} Browser notifications, with message previews off by default
{% icon "badge-check" %}

Identity & verification

  • {% icon "check" %} Emoji (SAS) verification between people and between your own devices
  • {% icon "check" %} Cross-signing: verify a person once, trust all their verified devices
  • {% icon "check" %} Clear warnings when someone's identity changes
  • {% icon "check" %} Per-message and per-room encryption indicators that tell the truth — unencrypted rooms are labelled as such
  • {% icon "check" %} Session list for every device, with remote sign-out
{% icon "video" %}

Voice & video

{% if lumen.calls_enabled %}
  • {% icon "check" %} One-to-one and group calls with voice, video and screen sharing in the web app
  • {% icon "check" %} MatrixRTC, the Matrix calling standard, through a media server (SFU) on this server
  • {% icon "check" %} Per-frame end-to-end encryption with keys exchanged over Matrix: the SFU only forwards ciphertext
  • {% icon "check" %} No recording component on the server
  • {% icon "info" %} Calls need UDP or TCP port 7881; networks that allow only HTTPS on port 443 can't join calls yet
{% else %}

Calls are turned off on this server by its operator. When they are on, {{ brand.short_name }} uses MatrixRTC with per-frame end-to-end encryption, so the call server only forwards ciphertext.

{% endif %}

Recovery

  • {% icon "check" %} Encrypted server-side key backup (Matrix secure backup)
  • {% icon "check" %} Recovery key generated on your device and never sent to us
  • {% icon "check" %} Account recovery with MFA recovery codes, email reset (when configured) or assisted recovery

Accounts & teams

  • {% icon "check" %} Two-factor authentication: authenticator apps, security keys (WebAuthn) and recovery codes
  • {% icon "check" %} Workspaces with owners, admins and members
  • {% icon "check" %} Invitations by link or email, with seat limits enforced on the server
  • {% icon "check" %} Workspace policy: require MFA before members can sign in to chat
  • {% icon "check" %} Self-service data export and account deletion
{% icon "waypoints" %}

Matrix network

  • {% icon "check" %} Built on Matrix, the open standard for decentralised messaging
  • {% icon "check" %} Federation with independently operated Matrix servers
  • {% icon "check" %} Works with standard Matrix apps such as Element
  • {% icon "check" %} Operator-defined federation policy: open, allow-list or closed
  • {% icon "check" %} TLS 1.3, with hybrid post-quantum key exchange where your browser supports it
{% icon "network" %}

For operators

Running {{ brand.short_name }} for a team or community? The server comes with a private operator console that isn't on the public internet.

  • {% icon "check" %} Console reachable only through WireGuard, an SSH tunnel or allow-listed addresses
  • {% icon "check" %} WireGuard on by default, with a preshared key for every operator device
  • {% icon "check" %} Operator MFA, roles, re-authentication for sensitive actions and a tamper-evident audit log
  • {% icon "check" %} Health checks, encrypted backups with restore checks, and updates that roll back on failure
