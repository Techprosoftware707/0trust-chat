One network, many independent servers

Rooms are replicated

Encryption is end-to-end across servers

Federation carries ciphertext. Servers sign their traffic, but neither ours nor theirs can read encrypted messages.

Why Matrix

  • Open standard. The protocol is published and implemented by many independent projects, so your conversations don't depend on one company.
  • End-to-end encrypted by default. Olm/Megolm through the audited vodozemac library, cross-signing and emoji verification, and an encrypted key backup unlocked by a recovery key only you hold.
    • {% if lumen.calls_enabled %}
  • Encrypted calls. Calls use MatrixRTC with per-frame end-to-end encryption, so the call server only forwards ciphertext.
    • {% endif %}
  • No lock-in. Use other apps, talk to other servers, or run your own.

Federation is not peer-to-peer

In a federated network your device talks to your homeserver, and homeservers talk to each other. Your server stores and forwards your encrypted messages and sees metadata about your conversations. That's different from peer-to-peer systems such as Tox, where devices connect directly and nothing is stored centrally — at the cost of both people needing to be online and of weaker multi-device support. We chose federation for reliable delivery, history on every device and interoperability with the wider Matrix ecosystem.

Run your own server

The complete {{ brand.short_name }} stack — homeserver, web chat, website, customer portal, operator console, backups and monitoring — installs on a fresh Ubuntu 24.04 server:

sudo bash install.sh

The installer checks your server and DNS, obtains TLS certificates, configures Matrix discovery and federation, sets up a firewall, encrypted backups, health checks and WireGuard for private operator access, and refuses to report success until every public endpoint actually responds. See the self-hosting guide.

{% icon "network" %}Your operator console stays off the public internet: reach it through WireGuard (on by default, with a preshared key per device), an SSH tunnel or allow-listed addresses. Private administration with WireGuard.
